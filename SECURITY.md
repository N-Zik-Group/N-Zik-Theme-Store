# 🔒 Security Policy

## Reporting a Vulnerability

Report suspected vulnerabilities privately through [GitHub Security Advisories](https://github.com/N-Zik-Group/N-Zik-Theme-Store/security/advisories/new). You can also contact a maintainer privately through the [N-Zik Discord](https://discord.gg/bneHC7QRje).

Include the affected theme ID and revision, the relevant file or catalog URL, and the potential impact. Remove personal data, credentials and access tokens before sending evidence. Keep details private while maintainers investigate.

For vulnerabilities in the Android app itself, see the [N-Zik security policy](https://github.com/N-Zik-Group/N-Zik/security/policy). Standard catalog bugs belong in the repository's issue forms.
